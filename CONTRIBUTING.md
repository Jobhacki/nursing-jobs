# Contributing to the Nursing jobs list

Help nurses find openings that match their qualifications. Include the license and care setting when the employer states them.

## What belongs in this list

RN, LPN, nurse practitioner, nurse educator, and other nursing roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, location, and required nursing license.

[Open the Add a job form](https://github.com/Jobhacki/nursing-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the nursing role title, employer, link, and whether the posting is missing or marked filled.

[Open the Report a dead link form](https://github.com/Jobhacki/nursing-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
